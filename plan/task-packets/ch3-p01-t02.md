## Required Artifacts

- 不可变 `Ch3ExperimentConfig`，字段与实施计划的 API 合同精确一致。
- 使用 `yaml.safe_load` 的 `from_yaml()`，以及 `with_overrides()`、`validate()`、`to_dict()`。
- 三份只含算法参数的正式 YAML，分别对应 MetroPT-3、FD004、TEP 的协议窗口、预算、seeds 和缺失设置。
- `PyYAML==6.0.2` 依赖声明与覆盖 schema、formal 限制、三配置载入的单元测试。

## Rejection Checks

- 非核心 seed、非法缺失率、head、run level 或非正窗口参数被接受。
- formal 配置允许少于 2 epoch、正数 train/eval batch 截断，或非 `split_seed=2026`。
- tuning 配置可以请求 test loader。
- YAML 使用手写字符串解析，或包含 data/output 路径、机器地址、账号、主机、端口或远程链接。
- 修改训练入口、数据集、模型、checkpoint、prediction、metrics 或 `result/`。

## Review Gates

1. 规格符合性：全部 API 字段、四种 run level、formal 约束与三数据集参数均与协议一致。
2. 质量：仅使用安全 YAML 解析；未知/无效配置在载入或覆写时拒绝；YAML 保持可移植且不承载运行时路径。
