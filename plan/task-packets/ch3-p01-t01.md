## API And Decision Inputs

```python
@dataclass(frozen=True)
class RuntimePaths:
    project_root: Path
    data_root: Path
    output_root: Path

def resolve_runtime_paths(
    data_root: str | None,
    output_root: str | None,
    environ: Mapping[str, str],
    *,
    require_existing_data: bool = False,
) -> RuntimePaths: ...
```

- 仅接受 `KST_PROJECT_ROOT`、`KST_DATA_ROOT`、`KST_RESULT_ROOT` 三个环境变量。
- 解析优先级固定为 CLI 参数、环境变量、`project_root / dataset` 或 `project_root / result`。
- 相对路径以解析后的项目根为基准；返回值均为规范化绝对 `Path`。
- formal 模式必须拒绝不存在的数据根，并给出可定位的错误信息。
- 不写入或读取数据集、结果、checkpoint、metrics；不得引入机器绝对路径、主机、端口或外部链接。

## Rejection Checks

- CLI 未覆盖环境变量，或环境变量未覆盖默认值。
- 返回相对路径、未规范化路径，或将运行目录依赖于调用时工作目录。
- formal 模式静默接受不存在的数据根。
- 修改训练入口、科学实验参数、数据集内容或 `result/`。

## Review Gates

1. 规格符合性：四个路径优先级、规范化和 formal 缺失目录测试均通过。
2. 质量：实现只依赖标准库，docstring 明确优先级、相对路径基准和 formal 校验边界。
