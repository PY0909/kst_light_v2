# Sources

This directory contains local PyTorch adaptations for the project comparison
protocols. The code is not a vendored copy of the upstream repositories. The
models reuse the same industrial datasets, split files, missing masks, risk
label rules, Platt calibration, and validation-normal q95 threshold protocol
used by the main project.

## PatchTST-Gaussian

- Official repository: https://github.com/yuqinie98/PatchTST
- Paper: https://arxiv.org/abs/2211.14730
- Local adaptation: channel-independent patch tokens, Transformer encoder, and
  diagonal Gaussian forecasting head.

## ODE-RNN

- Reference repository: https://github.com/YuliaRubanova/latent_ode
- Paper: https://arxiv.org/abs/1907.03907
- Local adaptation: lightweight Euler ODE hidden evolution between observed
  timestamps, GRUCell observation updates, and diagonal Gaussian forecasting
  head. No `torchdiffeq` dependency is required for this baseline.

## tPatchGNN

- Official repository: https://github.com/usail-hkust/t-PatchGNN
- Paper page: https://openreview.net/forum?id=UZlMXUGI6e
- Local adaptation: masked temporal patch statistics followed by adaptive
  dynamic sensor graph message passing and a diagonal Gaussian forecasting head.

## ProFITi

- Official repository: https://github.com/yalavarthivk/ProFITi
- Paper: https://arxiv.org/abs/2402.06293
- Local adaptation: GRU observation encoder, query conditioning, and the
  project-local ProFITi-style normalizing flow head with the existing Shiesh
  fallback and numeric guards.

## KAFNet

- Official repository: https://github.com/zhouziyu02/KAFNet
- Paper: https://arxiv.org/abs/2508.01971
- Local adaptation: project-local `KAFNetEncoder` with a diagonal Gaussian
  forecasting head.

## Common Project Additions

All baselines share:

- `create_protocol_datasets(...)` for MetroPT-3, C-MAPSS, and TEP.
- Frozen `.npz` missing masks generated by `generate_or_load_split_masks(...)`.
- Best-valid checkpoint selection by validation CRPS.
- Risk scores calibrated by validation-only Platt calibration.
- Official risk F1 threshold: q=0.95 of validation normal calibrated risk
  scores.
- No test labels are used for threshold, orientation, calibration, or checkpoint
  selection.
